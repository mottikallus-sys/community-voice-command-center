# Community Voice Command Center

Visibility-first internal company board. Open `index.html` in a modern browser or deploy it to an access-controlled static host.

- Desktop: three-column board; tablet: two columns; mobile: single column with optional compact two-column overview.
- Search, add, edit, delete, export and import company items.
- Data is saved in browser local storage only. Export JSON to transfer changes between devices.
- No login, shared database, Monday.com integration, or production hosting is implemented yet.
- Keep deployment private and access-controlled; private source repository alone does not protect a deployed website.

Mobile browser testing remains to be completed. The compact layout is a card overview, not a zoomable canvas.
